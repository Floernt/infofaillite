# Comprendre la procédure de faillite

La faillite est une procédure collective organisée par le Livre XX du Code de droit économique. Cette rubrique en expose les règles dans l'ordre où on les rencontre : ce qu'est une faillite et qui y intervient, comment elle se déroule du jugement à la clôture, quels effets elle produit sur le patrimoine du failli et sur les actes conclus avant le jugement, et quelles procédures permettent parfois de l'éviter.

Si vous êtes directement concerné, les rubriques [Je suis en faillite](../faillis/README.md) et [Je suis créancier](../creanciers/README.md) partent de votre situation et renvoient ici pour le détail des règles.
